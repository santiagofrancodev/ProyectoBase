# Entregable 2: Product Blueprint — Semana 2

Este directorio agrupa los artefactos y documentos de diseño de producto correspondientes a la **Semana 2** del programa **Blockchain Builders 101**.

El objetivo de esta fase es traducir el problema priorizado en la Semana 1 a una especificación de producto viable (MVP), backlog priorizado de historias de usuario, criterios de aceptación, flujo futuro y tablero Kanban en GitHub Projects.

---

## Estructura de la carpeta

- **[`ProductBlueprint.md`](ProductBlueprint.md):** Documento grupal que consolida el Lean Canvas, el alcance del MVP, el flujo de usuario futuro, las decisiones de arquitectura de datos y el plan de validación. *(Estado: Borrador estructural pendiente de historias individuales y consenso).*
- **[`SantiagoFranco.md`](SantiagoFranco.md):** Historias de usuario propuestas por Santiago Franco con formato estándar, criterios de aceptación y priorización MoSCoW.
- **[`GustavoArcila.md`](GustavoArcila.md):** Plantilla individual reservada para Gustavo Adolfo Arcila Trujillo, con estructura vacía para que redacte sus historias y realice su propio commit individual.
- **[`kanban.md`](kanban.md):** Guía de configuración para crear y vincular el tablero público en GitHub Projects con sus columnas de flujo y automatización.
