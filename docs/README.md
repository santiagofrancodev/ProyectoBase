## Principios de documentación del equipo

1. **Evidencia verificable y honestidad:** Distinguir tajantemente entre hechos observados en terreno, hipótesis de diseño y elementos pendientes de validación empírica.
2. **Privacidad por diseño (Privacy by Design):** Prohibición absoluta de incluir datos personales identificables (PII), direcciones de viviendas, datos de contacto de damnificados o imágenes sensibles.
3. **Autoría y disciplina de commits:** Cada integrante del equipo mantiene la autoría de sus propuestas e historias de usuario individuales, registrándolas directamente en el repositorio mediante su propio commit.
4. **Enfoque conceptual antes de codificar:** No apresurar código ni contratos inteligentes en fases de descubrimiento y formulación del problema.
